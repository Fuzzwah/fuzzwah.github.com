FUZZWAH'S PROJECTS

Welcome to my tiny corner of the internet. This is where I share the things I've spent my spare time building. It is 2026 — this page last caught up with reality in 2016, so consider this one long-overdue git pull.

I do not claim to be some kind of geek genius; most of my projects are neither original nor unique. I like to believe I have the spirit of a bricoleur — I make things from whatever materials and information are at hand, which usually means standing on the shoulders of code, tools and hardware built by other people.

Right now that means agentic-AI tooling, terminal UIs, Dungeon Crawl Stone Soup career stats, sim-racing dashboards and dinner. Previously it meant XBMC plugins, IRC bots, RFID music boxes and online-poker tools. Basically: if I'm interested in something, I end up building something to enjoy it more.

# ~/simracing — the iRacing lab (2018 – present)

I got hooked on the iRacing simulator, and of course that meant obsessively collecting data and building tools around it.

  • 2026-09 iracingreports.com ACTIVE django · rabbitmq · postgresql

    Statistics and analysis of iRacing drivers and official series results, live at iracingreports.com. A Python + RabbitMQ collector ingests iRacing service info and race results into PostgreSQL; the Django 4.2 app behind the site serves it up. The companion Discord bot brings those reports into Discord too. This is the grown-up, deployed end of the stats project family that starts in the museum below.

    [web app][Discord bot][code: private]

  • 2026-03 simhub-dash-fuzzwah-v2 ★6 ACTIVE simhub · custom css

    My custom SimHub dashboards, tuned for the cars I race. The left panel changes per car — adjustable ABS, TC and ARB on track where available — covering GT3s, GTEs, the Ford GT and V8 Supercars.

    [repo]

  • 2025-12 irFFB ★107 ARCHIVED FORK c++

    The single most-starred thing on my profile: a fork of the classic iRacing force-feedback utility, kept alive with fixes and releases. Archived once I was sure I wouldn't touch it again — but it remains the reference FFB tool on the service.

    [repo]

  • 2020-05 race-info ★9 SHELVED python

    A pre-race briefing on your rivals: pulls each driver's licence and iRating from the Session Info API, estimates strength of field and championship points down to 5th, then digs through each driver's series history — races run, standing, average finish, average incidents.

    [repo]

  • 2021-06 iRacing-My-Results-Highlighter ★3 SHELVED javascript · userscript

    Highlights the rows that are yours in iRacing's event results tables, so you can find yourself in a 40-car field at a glance.

    [repo]

  • 2019-08 iRacing-Series-Participation ★2 SHELVED javascript · userscript

    Puts a barchart on each iRacing series page showing driver participation and strength of field, so you know whether a series is worth entering that week.

    [repo][openuserjs]

# ~/lab — current obsessions (2025 – present)

  • 2026-09 dcss-morgue-report ACTIVE python · stdlib only

    Dungeon Crawl Stone Soup is a roguelike that writes a "morgue" file for every run. This turns a whole career of morgues into one self-contained, stats-heavy HTML report — charts, milestone records, per-monster and per-branch breakdowns, layered character portraits wearing the gear they died in, and a sortable table of every game. Standard library only: no deps, no build step, no internet needed to view it.

    [repo][live example report]

  • 2026-04 recipes ★6 ACTIVE markdown · python

    The recipes I actually cook and eat, each in a handy markdown file with a photo of the result. 99 recipes at last count, and growing. A Jekyll companion site — evolved from the old Chowdown template — serves them up with a photo pipeline, search and a changelog. My most-starred original project, which says something about the internet.

    [repo][site]

  • 2026-04 books.fuzzwah.com ACTIVE jekyll · goodreads export

    My reading history, escaped from Goodreads. A Jekyll site generated from a library export — books, reviews and recommendations, with OpenLibrary covers.

    [site][repo]

  • 2025-10 rfid-triggered-music ACTIVE python · flask · mpv

    Scan an RFID card, hear an album. Two machines: a Linux box handles the card reader and a Flask web interface for card-to-album assignments, and tells a macOS playback host to run mpv. The 2025 reboot of a project family that started in 2014 — see the museum below.

    [repo]

    A client/server harness for running multiple pi coding-agent sessions in parallel across git worktrees, with a native TUI client. Built because running agents over SSH on a Mac is a hotkey-theft nightmare. Early alpha; the core loop works end to end.
